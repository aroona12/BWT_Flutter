# 📚 Flutter Learning Tasks

This repository is a collection of various tasks and assignments completed during my initial Flutter learning phase. Each task focuses on a specific area, from basic Dart practice to simple database and backend integrations.

---

## 🛠 Tech Stack
- **Framework:** Flutter (Dart)
- **State Management:** Basic `setState` (Ephemeral state).
- **Storage & Backend:** Experimental use of `sqflite` and `Firebase` for basic CRUD operations.

## 📂 Tasks Overview

### 1. Task 1: Dart Practice
- Focused on core Dart programming concepts.
- Practiced variables, loops, and basic functions to build a foundation for Flutter.

### 2. Task 2: First App
- My very first Flutter application.
- Focused on the basic counter app and understanding the `StatefulWidget` lifecycle.

### 3. Task 3: Widgets & Navigation
- A deep dive into the top 10 most used Flutter widgets.
- Practiced moving between screens using the `Navigator` class.

### 4. Task 4: To-Do App (sqflite Integration)
- A basic To-Do list application.
- **Goal:** Practiced simple local data storage using the `sqflite` package. 
- *Note: Focused on basic Save/Delete functions.*

### 5. Task 5: Expense Tracker (Firebase Basics)
- A simple UI to track expenses.
- **Goal:** Introduction to Firebase integration.
- Practiced connecting a Flutter app to a Firebase console and performing basic data sync experiments.

---

## 📌 Summary
These tasks represent my journey of learning Flutter from scratch. The focus was on:
- Learning by doing (Task-based learning).
- Understanding how third-party packages (Firebase, sqflite) connect to Flutter.
- Building clean and simple UIs using basic widgets.

*These are educational tasks and serve as a foundation for my mobile development skills.*
